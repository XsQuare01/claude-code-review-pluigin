아래를 실행하고 출력을 **그대로** 사용자에게 보여준다.

```bash
node "${CLAUDE_PLUGIN_ROOT}/scripts/plugin-version.mjs"
```

`${CLAUDE_PLUGIN_ROOT}`가 비어 있는 호스트라면, 이 파일이 있는 플러그인
디렉터리를 기준으로 같은 스크립트를 실행한다.

출력을 요약하거나 숫자를 다시 세지 않는다. 버전과 경로를 눈으로 옮겨 적으면
**틀릴 수 있는 자리가 하나 늘어날 뿐**이고, 이 명령은 바로 그 종류의 착오를
없애려고 있는 것이다.

## 무엇을 보는 명령인가

버전 숫자만 확인하는 명령이 아니다. 리뷰 결과가 이상할 때 먼저 확인해야 하는
것은 **어느 규칙으로 돌았는가**다. 규칙 디렉터리 해석 순서(C-1)가 홈 디렉터리
사본으로 끝나기 때문에, 설치가 조금만 어긋나도 리뷰는 멀쩡해 보이면서 낡은
규칙으로 돈다.

출력에 `주의: 홈에 규칙 사본이 있다`가 보이고 모듈 수가 설치본과 다르면,
그 사실을 사용자에게 짚어준다 — 호스트에 따라 리뷰가 그쪽 규칙으로 돌 수 있다.
